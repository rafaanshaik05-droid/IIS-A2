Prompt Review

Privacy

When you ask for a rewrite, your draft prompt is sent to the provider selected below, using that provider’s key. Only the draft is sent, never your chat history. This happens even when "save prompt text" is off. Check the provider’s current terms for how it handles API data on your tier. Your keys and the study log stay in this browser (extension storage). A key is sent in a request header, and is never written to the log or shown in error messages.

Each provider keeps its own key. Switching provider never sends one provider’s key to another.
Use a local NIM container if you like (for example http://localhost:8000/v1/chat/completions). Any other host is asked for your permission when you save, and your draft and key are then sent there. Your key is only sent over https, or to this computer.

Study log

One row per review: token estimates, what the user decided, how many changes were selected, what the basic check flagged, and the cost of the review itself.

Test harness

Runs the fixed cases, compares the chatbot's answers to the original and the rewrite, and exports scored results.
