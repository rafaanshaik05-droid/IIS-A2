Prompt Review test harness

For each fixed case this makes the rewrite the user would see by default (only changes rated low risk by the model and the basic check), then asks the same model to answer both the original prompt and the rewrite. Answers are checked against criteria written in advance, and raters score them blind (A or B, in random order) using EVALUATION.md. Change one thing between runs, rerun, and compare. Ten or so cases show behaviour on those cases only, not general reliability.
